App: Inhibit (com.inhibit.user)

Google Play Data Safety Summary

Data Safety Question Answer Details
Does your app collect or share any user data? No Inhibit does not collect, record, or transmit user data.
Is data encrypted in transit? N/A No network data transmission occurs.
Can users request data deletion? N/A (No data stored) Zero user data is retained on servers.

Accessibility Data Handling

The Android AccessibilityService is used exclusively for ephemeral, on-device UI structure evaluation (detecting full-screen short-video containers). Accessibility events are processed strictly in RAM and discarded immediately without logging.
